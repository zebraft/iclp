# Library Lookup

Find scholarly books and article candidates in a conversation, check public library holdings and locations, compare book lists, and export selected records. The purpose is to make academic discovery and bibliography work easier through natural-language queries.

## Tools

- **OCLC WorldCat Search API v2:** bibliographic discovery and library holdings, through a configured provider.
- **Seven MCP tools:** catalog search, article search, locations, holdings checks, list preparation, selection export, and connection diagnostics.
- **Two skills:** library-holdings and book-selection.
- **Web and stdio transports:** a Worker-based service and a local MCP interface.

This is a sanitized source template. Connection details and institution defaults use placeholders; no original account bindings, credentials, or runtime records are included.
