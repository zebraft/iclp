---
name: book-selection
description: Compare scholarly bibliographies against the user's interests, help select records and export the chosen IDs.
---

Follow the user's request and stated research interests; explicit instructions override defaults.

1. Use supplied records and evidence from the current conversation. Preserve existing IDs; assign stable IDs once when absent. Normalize only when needed. For topic exploration, favor scholarly books, edited collections and academic journal articles, balancing recent research with relevant foundational work supported by evidence.
2. Explain relevance from supplied metadata or verified catalogue evidence. Keep scholarly value separate from local duplication, edition and format differences. Use library-holdings for discovery or holdings evidence; search the general web only when requested.
3. Complete a requested finite comparison in bounded batches, tracking failures and remaining records without repeated permission requests. Retain uncertain items for user choice rather than silently excluding them. Present concise comparisons and catalogue links in conversation.
4. Let the user choose IDs, then export exactly that selection. Preserve editions, formats, volumes and original IDs across export batches. CSV export does not send, save to institutional resources, submit a recommendation or purchase anything.

For duplicate identities, large exports or uncertain claims, read [selection evidence](references/selection.md). No persistent researcher profiles or private creator resources are used.
