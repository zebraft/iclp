Library Lookup

在 ChatGPT 對話裡找書、查館別與索書號。Search library records and locations from a ChatGPT conversation.

使用方式 / How to use

  1. 在 ChatGPT 安裝並選用 Library Lookup，依畫面完成首次連線。Install and select Library Lookup in ChatGPT and complete any initial connection shown.
  2. 直接提問：「查《唐代的文学精神》的館藏位置與索書號。」Ask: “Find the library location and call number for 唐代的文学精神.”
  3. 不必在本頁登記讀者帳號，也不必提供 OCLC 金鑰。No separate reader registration here or personal OCLC key is needed.

查詢範圍 / Scope

書名、作者、關鍵詞、ISBN、ISSN 或 OCLC 號碼；回傳可取得的書目、館別、位置、索書號與卷期。預設查 DEMO 院內館藏；也可指定「搜尋整個 WorldCat，不限院內館藏」。全球書目結果不代表院內持有，院內未查得也不等於全院無館藏。Search by title, author, keyword, ISBN, ISSN or OCLC number. Read available catalog and local holdings data. AS holdings (DEMO) is the default. Ask to search all WorldCat for worldwide discovery regardless of AS ownership; those results do not establish AS holdings.

目前僅提供館藏查詢，不處理個人借閱帳號、續借或採購。Lookup only. Personal loans, renewals and purchasing are outside the current scope.

試用版本；公開目錄發佈仍須完成審查及發布者資料。Pilot version. Public-directory release still requires review and completed publisher information.
